# Feature 2: Frontend Dashboard

## Goal
Visualize telemetry data in real-time using React.

## Components
- Dashboard page
- Graphs for:
    - EPS
    - ADCS
    - Payload
    - System
- Auto-update every 30 seconds via backend API

## Micro-tasks
1. Create React project in `frontend/`
2. Implement dashboard page
3. Implement graph components for EPS, ADCS, Payload, System
4. Connect to backend API endpoints
5. Implement error handling for API failures
6. Write unit tests for React components
7. Commit and open PRs
